# 🌉 **Soul Bridge**

> 🪶 *Your AI Reading Companion that explains English books in Hinglish — with emotions and desi vibes.*

---

## 💡 **About the Project**

**Soul Bridge** helps Indian readers deeply understand English books — not just what’s written, but what’s *felt*.
It takes any confusing passage and translates it into *conversational Hinglish*, explains its emotional essence, connects it to *Indian culture*, and defines complex words — just like a wise friend would.

Built using **React + Express + OpenAI GPT-4o-mini**, Soul Bridge is where **literature meets empathy and technology**.

---

## 🧠 **Core Features**

| Feature                        | Description                                                            |
| ------------------------------ | ---------------------------------------------------------------------- |
| 💬 **Hinglish Interpretation** | Explains passages naturally in Hinglish — jaise hum baat karte hain.   |
| ❤️ **Emotional Context**       | Reveals the deeper emotional meaning behind the author’s words.        |
| 🇮🇳 **Desi Connection**       | Connects the message to Indian culture — from Bollywood to daily life. |
| 📘 **Word Meanings**           | Simplifies complex words and phrases with Hinglish-friendly meanings.  |
| ⚡ **Instant Understanding**    | Paste any paragraph and get clarity within seconds.                    |

## 🧩 **Tech Stack**

* ⚛️ **Frontend:** React + Vite + TailwindCSS
* 🧠 **AI Engine:** OpenAI GPT-4o-mini (via Express API)
* 🌐 **Backend:** Node.js + Express
* ☁️ **Deployment:** Vercel

## ⚙️ **Local Development Setup**

```bash
# 1️⃣ Clone the repository
git clone https://github.com/your-username/soul-bridge.git
cd soul-bridge

# 2️⃣ Install dependencies
npm install

# 3️⃣ Add your OpenAI API key
# Create a .env file in the project root
echo "OPENAI_API_KEY=your_api_key_here" > .env

# 4️⃣ Run locally
npm run dev
```

Your local servers:

* API → `http://localhost:3000`
* Frontend → `http://localhost:5173`

---

## 🌍 **Deployment**

Soul Bridge is deployed on **Vercel** for effortless scalability.

To deploy your own version:

```bash
vercel
```

Make sure to set your environment variable in Vercel Dashboard:

```
OPENAI_API_KEY = your_api_key_here
```
